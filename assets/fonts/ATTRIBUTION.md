# Bundled fonts

Each family here is a subset of an upstream release, pinned to two static
weights and reduced to printable ASCII by `tool/subset_fonts.py`. The subsets
are derivative works and carry their original licences.

| Family | Upstream | Licence |
| --- | --- | --- |
| Source Serif 4 | [Adobe Fonts](https://github.com/adobe-fonts/source-serif) | SIL Open Font License 1.1 |
| JetBrains Mono | [JetBrains](https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |
| Inter | [Rasmus Andersson](https://github.com/rsms/inter) | SIL Open Font License 1.1 |

The SIL OFL permits bundling, modification and redistribution — including the
subsetting done here — provided the licence travels with the fonts and the
Reserved Font Names are not used for modified versions. These files keep their
original family names because the glyph outlines are unmodified; only the
character set and the variable-font axes have been reduced.

Full licence text: <https://openfontlicense.org/>
